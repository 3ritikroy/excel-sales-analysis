# Excel Sales Analysis

A hands-on Excel project where I practiced data analysis using a Sales dataset.

## Dataset

* 18 columns
* 113,036 data records
* Sales-related fields including Date, Country, State, Product, Order Quantity, Cost, Revenue and Profit

## What I Practiced

### PivotTables

* Created PivotTables from the original Sales data
* Analyzed Revenue, Cost and Profit by Country
* Calculated Revenue contribution as a percentage of total revenue
* Practiced Calculated Fields
* Analyzed Revenue by Country and Year

## Tools Used

* Microsoft Excel
* PivotTables

This project is part of my journey to develop practical Data Analysis skills through hands-on work with real-world datasets.

More analysis and visualization will be added as I continue learning Excel.
